# Cool Dudes Window Cleaning — Python Field Desk

Python/Streamlit rebuild of the Cool Dudes Window Cleaning dashboard.

Run locally:

    python -m pip install -r requirements.txt
    streamlit run app.py

The project includes dashboard metrics, bookings, an interactive Fremont territory map with polygon drawing, doorstep status tracking, monthly goals, account profile controls, and JSON export.

The current app keeps working data in the Streamlit session. Secure authentication and a shared cloud database are not implemented yet.
